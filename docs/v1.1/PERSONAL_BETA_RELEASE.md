# Code2Plain v1.1 — Personal Beta

## Product thesis

A visual learning layer for AI-generated code.

AI writes it.
Code2Plain makes sure you learn it.

---

## v1.1 capabilities

### Learning

- session-aware learning tracking
- persistent learning profiles
- new / practicing / familiar progression
- adaptive concept prioritization
- session learning digest
- ES / EN / FR learning output

### Automation

- automatic session-end detection
- automatic digest generation
- automatic mobile delivery path

### Device delivery

- secure one-time device pairing foundation
- device registry and revocation
- notification provider abstraction
- native APNs architecture
- real HTTP/2 APNs transport implementation
- iPhone companion source foundation
- free physical iPhone proof adapter using ntfy

### Commercial architecture

- account-scoped entitlements
- Free / Pro plan boundary
- mobile digest gating
- upgrade without device re-pairing
