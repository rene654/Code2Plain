# Code2Plain

Code2Plain turns Python code into simple A → B explanations for business users, analysts, and non-programmers.

## Problem

Software code is often difficult to understand for people without a programming background.

Code2Plain aims to bridge that gap by showing technical code alongside a clear explanation of:

- What goes in
- What transformation happens
- What comes out

## Initial MVP

The first version will support:

- Python code input
- Code viewer/editor
- Simple deterministic explanations
- Line or block selection
- A → B explanations
- Desktop interface using PySide6

## Planned Architecture

Code Editor → Code Analyzer → Explanation Engine → Explanation Panel

## Future Direction

Future versions may include:

- Python AST analysis
- AI-assisted explanations
- Multiple explanation levels
- Additional programming languages
- Integration with Ralph OS
